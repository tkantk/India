# Fact check

Every checkable claim in the seed content, with the source it was checked
against. The rule this file exists to enforce: **a slightly vaguer true
sentence beats a precise false one.** Where a number could not be confirmed
the line was rewritten until what it says is defensible, and the rewrite is
recorded in the Notes column.

Sources are named by publication. Government of India / state-government
sources (Incredible India, Rajasthan Tourism, Kerala Tourism, Odisha Review,
ASI, Survey of India, IMD), UNESCO and institutional science were preferred
over travel writing.

**The rule for this file: a row means the source in it was actually read.**
If it was not, the row says so.

The first version of this table broke that rule. It cited Britannica in
fourteen rows, seven of them as the only source, while the preamble
simultaneously claimed Britannica was "cited only where a second source
agrees" — and Britannica in fact returned HTTP 403 to every automated fetch in
this pass, so no Britannica page was read at all. Those rows have been
re-sourced against pages that were genuinely fetched on 2026-08-21 and are
quoted here. Rows still resting on an unfetched source are marked **not
re-fetched** so the gap is visible.

**How to reach a Government of India source, for the next pass.** An earlier
version of this paragraph said `india.gov.in`, `legislative.gov.in` and UNESCO
"could not be reached" because they returned 403. That was wrong, and it is the
kind of wrong that quietly lowers the standard of a whole table: the 403 came
from the fetching tool's default user agent, not from the sites. `curl` with an
ordinary browser user agent reaches all of them. Several rows below were
upgraded from Wikipedia to the government source once that was discovered.
Known live and quotable: `india.gov.in/explore-india/...` (Physical Features),
`delhitourism.gov.in`, `asi.nic.in`, `nationalwarmemorial.gov.in`,
`ncert.nic.in` PDFs, `mha.gov.in` annual reports, and `mea.gov.in`'s copy of
the Constitution. Known dead: `india.gov.in/india-glance/profile` (404 live,
Wayback only), `asidelhicircle.nic.in` (DNS gone). `web.archive.org` was
rate-limiting (503) during this pass.

Checked 2026-08-21 unless stated otherwise.

## Not fact, and deliberately so

Three lines are invitations rather than assertions and have nothing to check:
`tour.02` ("like a giant kite dipping into the sea"), `tour.14` and every line in
`content/ui.json`. Similes are marked as similes so a child can tell the
difference between what India looks like and what India is.
